1. 登录与管理员角色

管理端按管理级别划分职责，级别决定裁决权与可见范围。登录方式与用户端一致（姓名 + 身份 + 学号 + 密码）。

角色级别主要职责审批权
辅导员3（最高）全局管理：发布活动、账号与权限、系统安全、终审终审
小班主任2班级日常管理、初审、发布活动初审 / 终审（范围内）
班委1协助考勤、执行考勤复核、部分初审初审
裁决采用两级制：初审由本级管理员裁决；被裁决人不服可申诉，进入上级管理员终审；终审后结果锁定，仍可再申诉一次进入更高一级。

2. 发布活动

「发布活动」用于创建考勤活动。支持单次活动与长期活动（长期活动可拆分多个子活动并按周重复），并可绑定活动范围、设置签到规则与备注。

2.1 关键字段

字段说明
名称 / 地点 / 备注展示给成员；备注用于补充说明（如迟到要求）。
开始 / 结束时间活动的时间范围；长期活动可设置重复规则。
签到规则可选「活动结束前有效（before_end）」等策略，决定签到窗口的判定方式。
时间偏移窗口相对活动时间的偏移分钟数（如提前 30 分钟开窗）。
活动范围绑定已绘制的围栏；启用范围核验时用于比对签到位置。
图 2-1　发布活动（单次 / 长期 / 重复 / 范围 / 规则）
签到窗口由服务端统一计算，客户端时间不作数；发布前请确认时间与规则无误。

3. 活动管理

「活动」页列出全部活动，可查看/编辑、查看参与统计（签到、在途、请假、缺勤人数）、结束或删除活动，并可核对活动范围与备注。

图 3-1　活动管理与统计

4. 活动范围

「活动范围」可在地图上绘制多边形围栏，用于签到时的范围核验与位置查看。支持手动绘制与批量导入，可命名、编辑、删除。

图 4-1　活动范围列表
图 4-2　范围编辑器（绘制 / 编辑多边形）
坐标以 GCJ-02 存储；若与地图存在系统偏差，可在创建时使用偏移校正。范围核验不阻断签到，结果仅作参考。

5. 班级签到（花名册）

「班级签到」以花名册形式展示某场活动的全员状态，可筛选、检索、手工补录 / 更正签到，查看已签到成员的定位，并导出考勤表。

  • 按活动查看：签到 / 在途 / 请假 / 缺勤 一目了然；
  • 手工补录：为漏签成员补记签到（会留痕，记录操作人）；
  • 查看定位：对已授权定位的签到，可在活动范围地图上查看其位置；
  • 导出：导出为表格用于归档。
图 5-1　班级签到花名册（补录 / 筛选 / 导出）

6. 审核中心

「审核」集中处理请假、补签、退签与申诉。初审由本级裁决，可选「通过 / 驳回 / 退回修改」并填写回复；申诉进入上级终审。

操作说明
通过计入请假 / 补记签到，并通知申请人。
驳回驳回申请并附理由，申请人可申诉。
退回修改退回申请人补充材料后重新提交。
终审对申诉作出最终裁决，结果锁定（仍可再申诉一次）。
图 6-1　审核中心（请假 / 补签 / 申诉）

7. 账号管理

「账号管理」用于查看本范围内账号、授予/收回权限与作用域、重置密码、协助注销等。权限按作用域（scope）下发，避免越权。

图 7-1　账号管理（权限 / 作用域 / 重置）
重置他人密码、修改权限等敏感操作均会写入数据流审计，请谨慎操作。

8. 日历报告

「日历报告」以日历与统计形式呈现全班出勤情况，可按活动或成员查看，便于汇总与上报。

13.2 常见问题

  • 成员无法签到？ 检查活动是否在窗口内、规则与偏移是否正确；必要时手工补录。
  • 定位不在范围？ 范围核验不阻断签到；确认围栏绘制与坐标系统是否正确。
  • 审核该谁处理？ 初审由本级处理；申诉的终审由上级管理员完成。
  • 误操作了？ 敏感操作均留痕，可在数据流中核查；请谨慎处理权限与密码类操作。
