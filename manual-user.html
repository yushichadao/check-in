1. 注册、激活与登录

首次使用需先在注册页激活账号，之后方可登录。账号由管理员预置或自主注册后由邮箱验证码激活。

1.1 注册 / 激活

  1. 打开注册页，填写姓名、学号、身份（普通学生）与登记邮箱；
  2. 点击「发送验证码」，到邮箱收取 6 位验证码并填入；
  3. 设置登录密码（至少 6 位，需同时含字母与数字），提交即完成激活。
图 1-1　注册 / 激活页（姓名 · 学号 · 身份 · 邮箱 · 验证码 · 密码）

1.2 登录

使用「姓名 + 身份 + 学号 + 密码」登录。同一账号最多允许一台手机 + 一台电脑同时在线，超出时旧会话会被顶下线。

图 1-2　登录页（账号 · 身份 · 学号 · 密码）

1.3 首次设置与找回密码

  • 首次设置：新激活账号首次登录需完成通知偏好等首次设置，完成后进入主界面；
  • 找回密码：在登录页点「忘记密码」，用登记邮箱收取验证码自助重置；若邮箱已失效，可联系管理员通过工单重置。
图 1-3　忘记密码（邮箱验证码自助重置）
邮箱仅用于接收验证码与系统通知，请使用本人可正常收信的邮箱，并可在「账号信息 → 账号安全 → 找回邮箱」中维护。

2. 签到

「签到」为默认首页。页面顶部「当前活动」展示最近一场活动的详细信息与你的状态；下方「我的状态」用于提交签到。

2.1 当前活动

活动卡展示名称、时间、签到窗口、签到规则、地点、活动范围与备注，并显示你的状态徽标（已签到 / 在途中 / 请假 / 缺勤）以及是否为「范围内」。

图 2-1　签到页（当前活动详情 + 我的状态 + 定位与提交）

2.2 提交签到

  • 在「我的状态」中选择 签到 / 在途中 / 请假，可选填地点，然后点「提交」；
  • 签到时间窗口由服务端计算，客户端时间不可信；窗口未开或已关闭时无法提交；
  • 若活动启用了活动范围核验，首次提交会询问是否授权上传定位，不授权也可正常签到；授权后系统比对是否在范围内，结果仅作参考，不阻断签到；
  • 签到一旦提交不能自行取消或修改，如需更正请联系管理员。
定位精度低于阈值（默认 200 米）时会被拒绝采集；系统不做后台持续定位，仅在签到时采集一次位置并随签到上传。

3. 活动

「活动」页列出你可见的全部活动，可查看名称、时间、地点、备注与配图，并了解该活动的签到要求（是否需要范围核验、签到窗口等）。

图 3-1　活动列表 / 活动详情

4. 日历报告

「日历报告」以日历形式呈现你个人的每日考勤状态，并给出统计概览，便于自查出勤情况。

图 4-1　个人签到日历报告

5. 签到记录

「签到记录」列出历史签到明细（活动、时间、状态、是否在范围内），可作为核对与申诉的依据。

图 5-1　签到记录明细

6. 申诉与补签

「申诉」页用于提交请假 / 补签 / 退签申请，以及对裁决结果提出复议（申诉）。裁决采用两级制：初审由本级管理员裁决，你对结果不满可申诉进入上级终审。

类型适用场景说明
请假活动未开始前提前提交，附理由与（可选）材料，管理员审核后计入请假。
补签活动结束且本人缺勤需系统允许补签；提交后由管理员审核，通过即补记签到。
申诉 / 复议裁决结果有异议进入上级终审，裁决锁定后仍可申诉一次。
图 6-1　申诉 / 补签 / 退签申请
补签申请可由运维端关闭；关闭后仅保留请假流程。请如实填写，虚假材料将被驳回并留痕。

7. 数据流

「数据流」展示你本人的操作记录（登录、签到、申请、裁决等）与系统对本人的相关操作，便于追溯。敏感字段以打码形式展示。

图 7-1　个人操作数据流

8. 消息中心

接收站内信与系统通知，如活动创建、签到开始、缺勤提醒、裁决退回与工单回复等。工单回复与系统消息为必提醒，不可关闭。

图 8-1　消息中心

9. 账号信息与登录设备

  • 账号信息：查看基本信息，管理账号安全（修改密码 / 找回邮箱 / 注销）与通知偏好；
  • 登录设备：查看当前在线设备，可下线陌生设备以保障账号安全。

10. 通知与界面偏好

「账号信息 → 通知偏好」中可对每类通知自选接收渠道：站内 + 邮件 / 仅站内 / 不接收；同时可开关「清爽模式」，该模式默认开启，仅影响本人界面，不隐藏任何功能。

未配置 SMTP 时，所有通知改由站内消息投递，不影响送达；邮件验证码等环节依赖 SMTP。

11. 关于与隐私

「关于系统」可查看版本与 MIT 软件许可协议，并可通过「反馈网站问题」提交工单。隐私政策说明个人信息的收集与使用范围。

12. 常见问题与温馨提示

12.1 常见问题

  • 收不到验证码？ 检查邮箱是否填写正确、是否被归类到垃圾邮件；稍后重试或联系管理员。
  • 无法签到？ 确认活动是否在签到窗口内、是否已提交过；窗口由服务端计算，请以页面提示为准。
  • 签到不能改？ 签到提交后不可自行修改，如填错请联系管理员更正。
  • 被顶下线？ 同一账号至多两台设备在线，超过时会顶下最早登录的设备。
  • 定位没有权限？ 仅在活动启用范围核验且你选择授权时才会采集；不授权同样可以签到。

12.2 温馨提示

  • 请使用本人邮箱与真实学号注册，避免影响考勤与通知；
  • 如遇问题，请先在「消息中心」查看是否有相关通知，再通过「关于 → 反馈网站问题」提交工单。
