夜间模式 · data-mode="dark"
怎么用：系统内每个页面顶栏右侧都有「夜间 / 白天」按钮（月亮 = 当前白天，太阳 = 当前夜间），点击即切换并记住选择； 没手动选过时跟随系统深浅色。本页为对照演示，不加载切换逻辑，两侧固定为白天与夜间，便于逐项比较。
覆盖范围：底色与底纹、卡片 / 浮窗 / 表格表头、侧边导航、输入框与按钮、分类标签、维护横幅与遮罩，均已按同一套变量适配，不存在刺眼的纯白块。
过渡实现：CSS 变量本身不能过渡，但使用它们的颜色属性可以。切换瞬间给根元素（演示页为预览容器）挂上 .theme-switching，让整棵子树的背景 / 文字 / 边框 / 描边做一次 0.32s 过渡，结束即移除； 系统开启「减少动态效果」时自动不做过渡。
